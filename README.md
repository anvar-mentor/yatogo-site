# YATOGO — одностраничный сайт

Лёгкий лендинг: регистрация и сопровождение бизнеса в Узбекистане.
Три языка — русский, узбекский, английский. Без сборки, без фреймворков,
без зависимостей: открывается как обычный HTML.

## Структура

```
index.html            разметка и SEO-теги
site.config.js        ← ЕДИНСТВЕННЫЙ файл, который нужно править
assets/css/style.css  стили и дизайн-токены
assets/js/i18n.js     тексты на трёх языках (237 ключей × 3)
assets/js/app.js      переключение языка, таблица тарифов, форма, трекер, отзывы
assets/js/reviews.js  20 отзывов на трёх языках — ⚠ ПРИМЕРЫ, заменить реальными
assets/fonts/         шрифт Manrope (локально, без Google)
api/lead.js           заглушка под Telegram-бота (пока не активна)
```

## Как работает форма заявки

Сейчас — **без бэкенда**. Клиент заполняет форму, нажимает «Отправить»,
и у него открывается ваш Telegram с уже готовым текстом:

```
Новая заявка с сайта — YATOGO

Имя: Иван Петров
Контакт: @ivan
Услуга: Регистрация СП ООО
Тариф: Premium
Комментарий: IT-услуги, учредитель гражданин Турции
Язык сайта: RU
```

Клиенту остаётся нажать «отправить» в Telegram. Сайт при этом полностью
статичный — заливается на любой хостинг.

### Если захотите, чтобы заявки приходили боту сами

Тогда клиенту не нужно ничего дожимать — заявка уходит молча.
Заглушка уже написана, её нужно только включить:

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Напишите боту любое сообщение, откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите оттуда `chat.id`.
3. Задеплойте проект на Vercel (или Netlify) и пропишите в
   Settings → Environment Variables:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. В `site.config.js` замените `leadEndpoint: ''` на `leadEndpoint: '/api/lead'`.

**Токен нельзя класть в `site.config.js`** или в любой другой файл, который
отдаётся браузеру — его увидит каждый посетитель и сможет угнать бота.
Он живёт только в переменных окружения хостинга, куда его и кладёт `api/lead.js`.

## Языки

- Определяется так: `?lang=ru|uz|en` в адресе → сохранённый выбор → язык браузера → русский.
- Выбор запоминается в `localStorage`, адрес обновляется — ссылкой можно делиться.
- Все тексты лежат в `assets/js/i18n.js`. Чтобы поправить формулировку,
  найдите ключ и отредактируйте — менять `index.html` не нужно.

## Дизайн

Палитра: графит + изумруд, светлый минимализм в духе Apple.

```
Фон       #FFFFFF / #F6F7F6
Текст     #14181C
Акцент    #0B7A5B
Наведение #096949
Подписи   #6B7280
Бордеры   #E6E8E6
```

Токены — в начале `assets/css/style.css`, в блоке `:root`. Поменяете там —
поменяется на всём сайте. Фон страницы — 96% белого, карточки — чистый белый.
Шрифт: Manrope, размещён на самом сайте (57 КБ, все начертания в одном файле).

## Отзывы

В `assets/js/reviews.js` лежат 20 отзывов-**примеров** для макета.
Перед рекламой замените их реальными отзывами клиентов (с их согласия):
недостоверные отзывы — это риск по закону о рекламе и для репутации.
Каждый отзыв — имя, роль и текст на трёх языках, оценка от 1 до 5.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Проверено

- Три языка переводятся полностью, непереведённых ключей нет.
- Горизонтального скролла нет ни на 1440px, ни на 390px.
- Валидация формы, подстановка тарифа по кнопке, генерация текста для Telegram.
- Ошибок в консоли нет.
- Клавиатурная навигация, `aria-label` у иконок, контраст, `prefers-reduced-motion`.
